# UI issues, for a focused session

Issues with the music-room pages, collected as they come up and fixed together later. The look
and flow decided so far are in `PLAN.md` ("The page, redesigned"): dark, purple for what to tap,
choosing and recording as two tasks.

## Exercise app

- **The score doesn't get enough room** (the player, 2026-10-17): "the UI for exercises is still
  quite cluttered and awkward. one big problem is that the scores are not always fully visible
  during preview or recording. too much clutter not enough space for the score." Both places: the
  preview of an exercise while choosing, and the record screen (and the take in progress). The
  score should come first; the rest gives way to it.
- **Exercises sharing a number** (2026-10-17): the eight voice count-in exercises are all "001", so the
  Ready screen's "Or next" says "Swap to 001" whichever comes next; it should name the exercise.
- **"on the Voice"** (2026-10-17): the Ready line reads "on the Voice" for the voice; it wants its own
  wording ("Your voice").
